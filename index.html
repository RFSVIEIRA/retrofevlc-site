Full Jukebox Mode

RetroFeVLC can also be used as a complete Jukebox. Save custom lists, recall them instantly, control volume, enable repeat, repeat track and shuffle. Create up to 32 individual lists per collection.

Essential Addons

Powerful tools that work together to make RetroFeVLC faster, smarter, and easier to use.

🚀 Start.exe (Starter)
The brain of the system. Auto-launches everything, syncs playlists, manages gamepads, and gives you a powerful system tray menu.
🔍 Search (F11)
Lightning-fast game search with per-system or full library mode. Fully gamepad friendly.
📋 MenuManager
Visual drag-and-drop menu editor. Create, reorder and organize categories and submenus easily.
🔄 Metadata ReGenerator
Creates optimized smaller hyperlists and shows accurate game counts.
🎨 GenreFixer
AI-powered automatic genre correction across your entire collection.
🛡️ KioskMode
Locks Windows into a dedicated console mode with auto-relaunch and password protection.
🌐 Story Translator
AI translation of game stories into multiple languages.
🖌️ Layout Editor
Visual drag-and-drop layout creator with tree view.
🏆 RetroRa Sync
Syncs RetroAchievements progress into your frontend for beautiful in-game stats.
🖼️ Marquee MonitorDuplicator
Mirrors gameplay to your marquee monitor with full control via JSON.
